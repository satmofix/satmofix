Privacy Policy / 隐私政策

Effective Date: 2026-11-22

1. Overview

Satmofix is a local GNSS/GPS tool for coordinates, waypoints and track recording. All core features work offline. The app may use system network-assisted positioning (Wi‑Fi / cell tower) to get a faster position fix. No user data will be collected, uploaded, transmitted or shared with servers or third parties.

2. Permissions & Local Data

Precise location permission is required for core functions:

  • Show real-time GNSS coordinates
  • Add and save waypoints
  • Record tracks
  • Position calculation

All coordinates, waypoints, tracks and user data are stored only on your device. Data will never be uploaded to the internet or cloud.

3. No Third-Party Data Collection

  • No ads
  • No third-party tracking or analytics SDK
  • No device or behavior data collection
  • No sharing of location, waypoint or track data with others

4. User Control

You may delete all saved tracks, waypoints and local data inside the app anytime. The developer cannot access or view your local location data.

5. Policy Changes

We may update this privacy policy from time to time. Updates will be published on this page.

6. Contact

If you have questions about this privacy policy, contact: satmofix@outlook.com

一、概述

Satmofix 是一款纯本地 GNSS / GPS 坐标、航点（打点）与轨迹记录工具。本应用核心功能全部离线运行。应用可使用系统提供的网络辅助定位（WiFi/基站）加快定位锁定速度，但不会收集、上传、传输、分享任何用户数据到服务器或者第三方平台。

二、权限与本地数据说明

本应用仅申请设备精准定位权限，用于实现核心功能：

  • 显示实时GNSS坐标
  • 添加、保存航点（打点标记）
  • 记录本地轨迹路线
  • 完成定位相关计算

所有定位坐标、航点打点、轨迹记录、用户操作数据，仅保存在您本机设备存储内。所有数据不会联网上传、后台自动上传、同步云端。

三、无第三方数据收集

  • 不含任何广告
  • 不含第三方统计、追踪、分析SDK
  • 不会收集设备信息、用户行为信息
  • 不会向任何第三方共享用户位置、航点、轨迹数据

四、用户数据控制权

您可以在App内随时手动删除全部轨迹、航点、本地缓存数据。开发者没有任何渠道查看、获取、读取您设备里保存的定位、航点、轨迹数据。

五、隐私政策更新

我们可能不定期更新本隐私政策，更新后的版本会直接展示在本页面。
